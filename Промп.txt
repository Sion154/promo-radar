## СТЕК И ДОГОВОРЁННОСТИ

- Frontend: чистый HTML/CSS/JS, без фреймворков и сборки. Скрипты подключаются через <script> в index.html (без модулей).
- Порядок скриптов: config.js → data.js → ui.js → filters.js → vk.js → tg.js → app.js
- Тема: тёмная, жёлтый акцент #f7c948 (как Bybit).
- Формат постов VK/TG дублируется в js/vk.js + js/tg.js и parser/parser.py — если меняешь один, меняешь второй.
- Парсер: Python 3.8+, только стандартная библиотека (urllib, json, pathlib, argparse).
- Категории: all, food, cinema, banks, marketplace, travel, games, subs.
- Я — новичок. Отвечай коротко, без теории, давай полные файлы целиком (не куски для замены). Каждый файл отдельно.

## ЧТО ОСТАЛОСЬ (Шаг 9 — деплой)

1. git init, commit, push на GitHub.
2. Включить GitHub Pages (main / root).
3. Проверить, что сайт работает на https://<username>.github.io/<repo>/.
4. Создать VK Standalone App → получить access_token (wall, groups, offline) → добавить как secret VK_ACCESS_TOKEN.
5. Узнать VK_GROUP_ID → добавить secret.
6. Создать Telegram-бота у @BotFather → токен в secret TG_BOT_TOKEN.
7. Добавить бота админом в канал → chat_id в secret TG_CHAT_ID.
8. Проверить workflow parser.yml вручную (workflow_dispatch).
9. Подключить домен к GitHub Pages (опционально).
